#  Airbnb Data Analysis Project

##  Project Overview
Airbnb has transformed the hospitality industry by enabling individuals to rent out properties globally. This project analyzes Airbnb listing data to understand pricing patterns, room type distribution, and customer engagement trends across neighborhoods.

##  Objective
The goal of this analysis is to uncover actionable insights that can help Airbnb:
- Understand pricing distribution across listings
- Identify popular room types and locations
- Analyze factors influencing listing prices
- Track customer engagement through reviews over time

##  Approach
- Data Cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Visualization of trends and distributions
- Identifying relationships between key variables

##  Key Questions
1. What is the distribution of listing prices?
2. How are different room types distributed?
3. How are listings distributed across neighborhoods?
4. What is the relationship between price and room type?
5. How has the number of reviews changed over time?

##  Business Value
This analysis helps Airbnb:
- Optimize pricing strategies
- Improve location-based recommendations
- Identify high-demand property types
- Enhance user engagement strategies
